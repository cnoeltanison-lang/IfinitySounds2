# Ifinity Sounds2

### How to Close
Since this script loops message boxes and locks the volume, it cannot be closed normally. Use one of the following methods:

1. **Force Shutdown:** Hold the physical power button on your computer until it turns off.
2. **Task Manager:** 
   - Press `Ctrl + Shift + Esc`.
   - Find all instances of `wscript.exe` in the **Details** tab.
   - Right-click them and select **End Task**.
3. **Command Prompt:** 
   - Press `Win + R`, type `cmd`, and hit Enter.
   - Type `taskkill /f /im wscript.exe` and press Enter.
